# checklist.md — 交付前逐条打勾

> 打印出来，或者贴进发布记录。**有一条不过就不要发。**

## A. 资源

- [ ] `python3 scripts/lint_assets.py` 全绿
- [ ] 每张切图满足其一：四角 alpha = 0，或叠在圆角遮罩容器里；且没有米色底 `#E7E3D6`、没有灰底 `#444444`
- [ ] 每一张切图的像素尺寸与图层数值一致（不是被拉伸的）
- [ ] 页面里没有任何 `.svg` 引用
- [ ] 半透明底板是图层重建的，不是截图抠的
- [ ] 字体文件在 `fonts/`，且 `document.fonts` 里状态是 `loaded`
- [ ] 视频首尾不是黑场；静音自动播放能起

## B. 视觉

- [ ] 舞台在 16:9 和 21:9 窗口下都等比放大，没有被裁边或留白错位
- [ ] 与设计稿同尺寸截图比对过，面板 / 文字行 / 图标位置对得上
- [ ] 字号用的是设计稿真值（不是 38/40 这种"看着差不多"的数）
- [ ] 文字颜色用的是设计稿真值（不是一律白色）
- [ ] 圆角半径来自图层（不是目测的 20/24）
- [ ] 没有用 CSS 渐变去"近似"设计稿里的图片纹理

## C. 交互

- [ ] 点任意一项：选中态整体迁移，旧项干净还原
- [ ] 连点 5 次，不出现两层同时高亮、不出现残影
- [ ] hover / 按下 / 键盘焦点 三种态都有明显反馈
- [ ] 不可点的元素要么真的禁用，要么不给指针
- [ ] 切换页面后，上一页的选中状态不会串到新页
- [ ] 移动端点按没有系统默认的黑色按压块
- [ ] 点线 / 分割线在缩放后仍然对齐

## D. 工程

- [ ] 业务文案全部在 `data/*.js`，`index.html` 里搜不到
- [ ] 新增页面只改了数据 + 一个容器 + 一段 CSS，没有动舞台
- [ ] `scripts/build.py` 打包后的文件数与预期一致
- [ ] 包体 < 60MB（超了先压视频）
- [ ] 发布后线上能打开，页面与本地一致
- [ ] `PROJECT.md` / `CHANGELOG.md` 已更新"为什么这么改"

## E. 交接（如果要给别人）

- [ ] `AGENTS.md` 里的规则和当前实现一致（没有过时条款）
- [ ] `RESOURCES.md` 已经发给设计并填过一轮
- [ ] 已知缺口写在 `PROJECT.md`「已知缺口」里，不是留在聊天记录里
- [ ] 字体授权范围写清楚（只随本项目分发）
