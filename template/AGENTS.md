## 1. 三条铁律

**一、切图优先。** 游戏 UI 的底板、纹理、行底板、图标、卡片，一律来自设计稿图层，或按图层真实数值生成的 PNG。

**二、不造状态。** 组件里没有的状态（选中、锁定、未拥有、未选中）先问，不许用 CSS 染色、加发光、加描边"补"一个出来。

**三、先量后写。** 坐标、圆角、字号、颜色都要有出处——图层数值或像素测量。目测等于错。

## 2. 什么必须切图，什么可以用 CSS

| 类型 | 做法 |
|---|---|
| 卡片、道具格、按钮、面板底板、行底板 | 切图，四角 alpha = 0 |
| 纹理、渐变、图案、材质 | 导出原图，不要重画渐变 |
| 图标、星标、勾选、光环、徽章 | 图层 PNG；矢量件先栅格化成 PNG |
| 纯色填充（胶囊、色块、分隔线） | 可以用 CSS 色值，值必须来自设计稿 |
| 文字 | 真文本 + 设计稿字体，不要切字 |

判断标准只有一句：**这个部件在 Figma 里是一张图/一个形状，还是一块纯色？**
是图就必须切图；是纯色矩形才允许 CSS。

> 注意区分两件事：
> - **按图层重画**（用设计值还原多层底板 + 纹理 + 圆角）是允许的，前提是每一层都在 Figma 里存在，数值可查。
> - **凭空发明**（自己配个渐变、自己画个描边、自己调个阴影）不允许。

## 3. 取图通道

- `get_screenshot` 只当人眼参考，**不能当素材**：它会把透明区压成不透明实色（米色 `#E7E3D6` 或灰 `#444444`）。
- 素材走 `get_design_context` 返回的 `assetPathPrefix/*.png` / `*.svg`，那才是带真 alpha 的原图。
- SVG 不进页面，落地前先栅格化为 PNG。
- 导出尺寸按图层原始数值 ×2，页面按 1x 使用。

## 4. 字体策略（必须执行）

1. **从设计稿读**：`get_design_context` 里的 `font-['家族:字重']`，或 `get_variable_defs` 的 text style。
2. **在本机找**：系统字体目录、`~/Library/Fonts`、`/Library/Fonts`、`/System/Library/Fonts`。
3. **找到 → 转 woff2 → 放进 `fonts/`**，`@font-face` 先写打包文件、再写 `local()` 兜底。
4. **找不到 → 停下来问用户要字体文件。** 不许静默回退系统黑体——那会让整个还原看起来"变味了"，而且很难被归因。
5. 字体只随本项目分发，不单独外发；交付时在 README 里写清这一点。

## 5. 禁止事项

- 页面里引 `<svg>` 或 `.svg` 文件（游戏 UI 一律 PNG）。
- 把整张截图裁一裁当切图。
- 用 `box-shadow` / `filter` / `mix-blend-mode` 发明组件的视觉状态。
- 用编造的文案填空（可以编，但要集中在一处数据文件里，并告知用户"这些是占位"）。
- 静默失败：拿不到素材、拿不到字体、拿不到状态，都要说出来。
- 不本地渲染就发布。

## 6. 验收线（交付前必须全过）

1. 切图要么四角 alpha = 0，要么叠在 `border-radius + overflow:hidden` 的圆角容器里（跑 `python3 scripts/lint_assets.py`，它会列出需要人工确认的那批）。
2. 页面文字用的是设计稿字体（`document.fonts` 里对应字体是 `loaded`）。
3. 每个可点元素有：默认 / hover / 按下 / 选中 / 键盘焦点。
4. 状态迁移不留残影（选中环整体迁移，不是叠加）。
5. 与设计稿同尺寸截图比对过，不是"我觉得差不多"。

## 7. 常用命令

```bash
python3 scripts/lint_assets.py     # 资源体检：缺文件 / 带底 / SVG / 字体
python3 scripts/build.py           # 按清单打包到 /tmp
bash scripts/deploy.sh             # 打包 + 发布
open index.html                    # 本地预览
open "index.html?page=guangzai"    # 直接落到某一页
```
