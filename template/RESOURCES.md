# RESOURCES.md — 设计师交接单

> 复制这一页给设计同学，让他按项填。填不满没关系，**写"没有"比留空更有用**——留空会让 agent 去猜。

## 一、必填七项

### 1. 画框清单

| 页面 | Figma 链接 | 节点 id | 设计尺寸 |
|---|---|---|---|
| 例：人类 | https://… | 5418:11205 | 4680×2160 |
| | | | |

> 要具体到画框，不要给文件首页。一个页面一张。

### 2. 组件变体清单（最容易漏，优先填）

| 部件 | 有哪些状态 | 哪个是最终版 | 备注 |
|---|---|---|---|
| 例：服装卡 | 常态 / 选中 / 锁定 | 选中用「选中=on」变体 | 选中变体比常态大 32×30 |
| | | | |

> 这次项目踩的坑：8 个"选中"变体里只有 1 张是真图，其余 7 张是同一个占位角色。
> **如果某个状态还没有美术，请直接写"没有"，agent 会停下来问，而不是自己造。**

### 3. 每个状态的切图

- 不透明件（卡、格子、按钮）：给整张图，或说明用哪个节点导出。
- 底板 / 纹理 / 行底板：给**单独图层**，不要合并。
- 半透明件（30% 透明的那种）：一定要给图层，截图抠不出来。

### 4. 字体

| 用途 | 家族 | 字重 | 文件 |
|---|---|---|---|
| 标题 / 数字 | 例：汉仪有圆 | 95W | 附 woff2 / ttf |
| 正文 / 描述 | 例：方正兰亭圆简体 | 准 | 附 woff2 / ttf |

**字体处理规则（写进流程，不用每次讨论）：**

1. agent 先从设计稿的 text style 读出家族与字重（不是靠看）。
2. 在本机字体目录里找同名字体。
3. 找到就转 woff2 放进 `fonts/`，页面 `@font-face` 先加载打包文件、再用 `local()` 兜底。
4. **找不到就停下来问设计/用户要字体文件**，不许静默退回系统黑体。
5. 字体只随本项目分发，不单独外发。

### 5. 动效

| 用途 | 文件 | 时长 | 是否循环 | 切换点 |
|---|---|---|---|---|
| 例：常驻待机 | standby.mp4 | 8s | 是 | 首尾要接得上 |
| 例：登场动画 | entrance.mp4 | 15s | 否 | 播完切回待机 |

> 附一句：首尾帧不要是黑场，否则循环接缝会很显眼。

### 6. 图标

- 优先给矢量源或独立图层；agent 会栅格化成 PNG。
- 尺寸写清是 1x 还是 2x（例：80×80 @2x = 160×160 文件）。

### 7. 文案

| 字段 | 有没有 | 说明 |
|---|---|---|
| 卡片名称 | 有 / 没有 | 没有就由 agent 编，集中在一个数据文件里 |
| 品质名称与颜色 | | |
| 描述 | | |
| 按钮文字 | | 装备 / 已装备 / 跟随 / 已跟随 |

## 二、可选但很有用

- **安全区**：四边各留多少，有没有刘海/圆角避让。
- **层级**：背景 / 面板 / 卡片 / 弹层，谁压谁。
- **禁用态**：不可点的元素怎么表现（变灰？隐藏？）。
- **空态**：没有内容时显示什么。

## 三、资源命名规范

```
pieces/            通用件（卡片、图标、按钮）
pieces/<页面key>/  某一页专用件
export/<页面key>/  该页背景图

命名：<模块>-<部件>[-<状态>].png
例：card-3.png、btn-equip.png、it-rowplate.png、gz-card-5.png
```

规则：
- 全小写 + 连字符，不用中文、不用空格。
- 状态后缀只有三种：`-on`（选中）、`-off`（常态）、`-lock`（锁定）。
- 同一部件不同尺寸不要用 `-2` 这种后缀，改尺寸应替换原文件。

## 四、交付前自查（设计侧）

- [ ] 每个状态都有对应的变体，或者明确写了"没有"
- [ ] 底板类没有和文字合并成一张图
- [ ] 字体给了文件，不只是名字
- [ ] 视频首尾不是黑场
- [ ] 文案要么给全，要么明确说"你来编"
