# 变更记录

只记「为什么」，不记「改了什么」——改了什么看 git 就行。

## YYYY-MM-DD · 标题

- **做法**：一句话说清改了什么。
- **原因**：不改会怎样（线上出问题 / 和设计稿对不上 / 用户反馈）。
- **代价**：这个改动牺牲了什么，后续要不要补。
