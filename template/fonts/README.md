# fonts/ —— 随项目分发的字体

字体必须打进站点，不能只写 `local()`：没装这两款字的机器会静默退回系统黑体，
整页观感变味，而且很难归因。

流程：

1. 从设计稿的 text style 读**家族名与字重**（不要靠看字形猜）。
2. 本机找到同名字体，转成 `woff2`，放进本目录。
3. 在 `index.html` 里写 `@font-face`：先指向打包文件，再用 `local()` 兜底。
4. 字体名写不对会静默失败 —— `npm run lint` 会检查 `fonts/` 是否为空、
   以及页面里有没有 `@font-face`。

**找不到字体时停下来问，不要用系统黑体顶上。**

授权范围：字体只随本项目分发，不要单独外发，跨项目复用要重新确认授权。
