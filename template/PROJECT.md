新窗口的 agent 第一份要读这个文件。它写的是「这个项目怎么组织」，不是「这次改了什么」。

## 一、这是什么

- 输出形态：纯静态页面，可交互、可发布
- 发布地址：（填上线地址）

## 二、目录职责

```
index.html          结构 + 样式（变量集中在 :root）+ 舞台缩放 + 交互
data/app.js         页面 / 卡片 / 文案的唯一真源
pieces/             切图，按 <模块>-<部件>.png 命名
fonts/              随项目分发的字体（woff2）
scripts/            lint_assets / build / deploy
deploy.manifest.json 只列页面真正引用的文件
AGENTS.md           给 agent 的硬规则（比本文档更优先）
WORKFLOW.md         八步流程与验收门槛
```

## 三、数据字段

`APP_DATA.canvas`：`{ w, h }`，设计画布尺寸。

`APP_DATA.pages[]`：

| 字段 | 含义 |
|---|---|
| `key` | 唯一标识，同时是 `[data-p]` 的值 |
| `title` | 页签文字与右侧标题 |
| `cards[]` | 本页卡片 |

`cards[]`：

| 字段 | 含义 |
|---|---|
| `id` | 唯一标识，选中态靠它匹配 |
| `name` | 名称，显示在右侧信息区 |
| `img` | 切图文件名（不带目录，默认指 pieces/） |
| `owned` | 是否已拥有；false 表示锁定态 |

## 四、交互状态机

```
默认（选中第一张）
  ├─ 点卡片 → 选中态迁移，右侧信息跟着换
  ├─ 勾「未拥有」→ 显示锁定卡；取消 → 隐藏并回收选中
  └─ 锁定卡被选中 → 出现「获取」类按钮
```

> 待填：本项目独有的状态（登场动画、跳过、二级页签联动等），逐个写清谁触发谁。

## 五、切图规则（最容易返工的一条）

| 部件类型 | 做法 |
|---|---|
| 不透明件（卡片、按钮、图标） | 整块切图 + 外层 `border-radius` + `overflow:hidden` |
| 半透明底板 / 带文字的面板 | 按设计值重画（底色 + 圆角 + 文字），不要整图裁切 |
| 有纹理的底板 | 底板色 + 单独一层纹理图 |
| 矢量图标 | 栅格化成 PNG；**页面里不要引 SVG** |

取图通道：`get_design_context` 的资源直链带真透明；截图接口会把透明区压成实色，整图裁切必然带底。
